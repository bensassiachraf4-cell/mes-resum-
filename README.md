# StudyHub ISET Nabeul

Site statique HTML/CSS/JavaScript pour GitHub Pages.

## 🌐 Site web
[Ouvrir StudyHub ISET Nabeul](https://bensassiachraf4-cell.github.io/mes-resum-/)

Dépôt GitHub : https://github.com/bensassiachraf4-cell/mes-resum-

## Publication
1. Envoie `index.html` à la racine du dépôt.
2. Ouvre **Settings → Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Le site sera publié à `https://bensassiachraf4-cell.github.io/mes-resum-/`.

## Personnalisation
- Les fiches de démonstration sont dans l'objet `details` à la fin de `index.html`.
- Les TP et cours officiels doivent être ajoutés depuis tes propres fichiers PDF ou liens Classroom/Drive autorisés.
- Les podcasts utilisent la synthèse vocale du navigateur. Pour de vrais MP3, ajoute des fichiers audio et leurs liens.
- Les emplacements vidéo sont prêts à recevoir des liens YouTube ou des fichiers MP4.
